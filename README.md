# 生活陪伴（精简）

只保留 **生活模拟** 和 **主动消息** 两件事的陪伴插件，按 AstrBot 人格隔离，
每个账号/适配器实例都可以单独换掉而不影响人格已有的生活状态。

原 `astrbot_plugin_private_companion` 功能非常全，但配置项上千、耦合很深。
这个插件是它的最小子集：没有关系分、没有群聊观察、没有生图、没有 QQ 空间、
没有 TTS、没有面板，只有一个人格在过日子，偶尔想找你说话。

## 它做什么

- **生活模拟**：每个人格每天生成自己的心情、精力、状态和日程，并随时间推进。
- **主动消息**：按日程和状态判断此刻要不要发消息；有免打扰、每日上限、
  最小间隔、连续未回应降速，以及一条完整的审计记录。

## 它不做什么

- 不接管 AstrBot 的回复人格，也不覆盖主回复。
- 不做群聊观察、关系分数、图片、语音、创作、QQ 空间。
- 不提供独立 WebUI。

## 配置（10 项）

| 配置项 | 说明 |
| --- | --- |
| 人格投递配置 | 每行 `人格ID = 平台实例ID:会话类型:会话ID` |
| 启用主动消息 | 总开关 |
| 启用生活模拟 | 关闭后只按人格设定说话 |
| 每日生成时间 | 默认 `07:30` |
| 主动最小间隔（分钟） | 默认 `90` |
| 每日主动上限 | 默认 `6` |
| 免打扰时段 | 默认 `23:30-07:30`，留空关闭 |
| 调度间隔（分钟） | 默认 `10` |
| 指定模型 | 留空用 AstrBot 默认会话模型 |
| 用户刚说话的静默期（分钟） | 默认 `15` |

### 人格投递配置

```
阿星 = matrix:FriendMessage:@alice:matrix.org
小满 = matrix:FriendMessage:@bob:matrix.org
```

- 左边是 AstrBot 人格名，右边是 `平台实例ID:会话类型:会话ID`。
- `平台实例ID` 是 AstrBot 平台配置里的实例 ID，Matrix 默认就是 `matrix`。
- `会话类型` 支持 `FriendMessage`（私聊）或 `GroupMessage`（群聊）。
- Matrix 的用户 ID 和房间 ID 自带冒号（`@alice:matrix.org`、`!room:server`），
  直接原样写就行，解析按前两段切分，不会切错。

**换账号/换实例只改这一行**：人格的生活状态按人格 ID 存在
`data/plugin_data/astrbot_plugin_matrix_companion/personas/` 下，与账号无关。

## 命令

| 命令 | 作用 |
| --- | --- |
| `生活` | 查看当前会话对应人格的状态、日程和主动判定结果 |
| `主动` | 立刻为当前人格执行一次主动判断（跳过免打扰与静默期，便于调试） |

## 面板

AstrBot 后台 → 插件 → 生活陪伴（精简）→ **生活面板**。

只读展示，每 15 秒自动刷新：

- 每个人格一张卡片：绑定路由、人格提示词是否匹配上、平台实例是否在线
- 当前心情、精力条、正在做什么、今天的完整日程（当前时段高亮）
- 主动状态：今日已发/上限、上次发送时间、连续未回应次数、当前判定及原因
- 最近 8 条审计记录（生成、跳过原因、发送内容、失败原因）

卡片上有两个按钮：

- **立即主动**：走真实判断链路——过闸门、问模型、发送、记账。等同聊天里发 `主动`。
- **测试发送**：只验证投递能不能通。跳过免打扰、配额、间隔、静默期和模型，直接发一条固定消息；
  不消耗当日配额、不更新上次发送时间、不增加未回应计数。成功会显示走的哪条链路
  （`send_by_session` 或 `core_fallback`），失败会原样显示上游错误。

日志级排查看 `data/plugin_data/astrbot_plugin_matrix_companion/personas/` 下的
`audit` 字段，面板只显示最近 8 条。

## 对话如何影响生活

生活状态不是只按日程推进，对话会反过来改写它：

1. 收到的消息和 Bot 发出的消息都会进入该人格的待处理队列（各最多 20 条）。
2. 每个调度周期最多回写一次：把最近对话交给模型，输出心情、精力、
   当前状态、一行事件记录，以及可选的「剩余日程调整」。
3. 回写后的状态会覆盖日程投影 30 分钟，所以面板里看到的是「刚和你聊完天」，
   而不是「正在看书」。
4. 事件记录进入面板的「最近发生」，也会作为上下文进入下一次主动判断。

面板命令（`生活`、`主动`、面板按钮）发出的内容是操作回执，不进入队列。

### 日程什么时候会变

只有明确约好的共同活动才会改日程，模糊提议和闲聊都不会：

| 你说 | 日程 |
| --- | --- |
| 下午一起看书吧 / 九点来找我 | 会插入对应时段 |
| 改天一起看电影 / 有空再说 | 不改 |
| 在吗 / 今天好累 | 不改，只更新心情和状态 |

改的时候按**时间重叠**合并：只替换冲突的那一段，没有冲突的未来安排保留。
所以模型即使只给出一条新增，也不会把剩下半天冲掉。

### 心情会跟着日程走

进入新的日程段时按活动类型调整心情和精力：

- 看书 / 整理 → 平静
- 吃饭 → 满足（精力 +5）
- 散步 / 逛 → 轻松（+2）
- 运动 / 跑步 → 有活力（-4）
- 通勤 → 有点累（-2）
- 看电影 / 音乐 / 游戏 → 放松

刚回写过的 30 分钟内以对话结果为准，不会被日程覆盖。

成本：有新对话时每个调度周期最多 1 次额外模型调用；没有对话就不调用。
把「调度间隔」调小，回写也会跟着变快。

### 用户状态识别

对话里关于对方自己的状态会被识别并影响主动判断（关键词规则，不额外调模型）：

| 类型 | 例子 | 效果 |
| --- | --- | --- |
| 去睡了 | 我去睡了 / 晚安 / 困了 | 记下「对方在睡」，**不再主动**，直到对方再发消息或超过 12 小时 |
| 醒了 | 我起床了 / 早安 / 睡醒 | 解除睡眠状态 |
| 出门 | 我出门了 / 上班 / 开会 / 在忙 | 记为「在外」，仍可主动但会避开打扰式内容 |
| 回来 | 我回来了 / 到家 / 下班 | 清除「在外」 |

否定表达（「睡不着」「还没睡」）不会触发睡眠。任何普通消息都会解除睡眠/外出状态。

同时，主动判断的提示词里会带上「对方最后说了什么」，并明确要求内容必须接得上，
不许自顾自换话题——这就是「你说去睡了，它还在讲自己日程」那类错位的修复点。

误判是可能的：关键词规则故意保守，宁可漏判也不乱判。看到不对可以在面板里对照
「对方」一行确认当前判定。

成本：有新对话时每个调度周期最多 1 次额外模型调用；没有对话就不调用。
把「调度间隔」调小，回写也会跟着变快。

## 与 AstrBot 人格的关系

- 人格由 AstrBot 的人格管理器提供，本插件只读取人格的 system prompt 作为语气来源。
- 人格到投递会话的映射完全由本插件的「人格投递配置」决定，
  不依赖 AstrBot 的会话人格路由，因此实例 ID 变化不会丢失模拟。
- 同一个人格重复配置会报错并拒绝加载该配置，避免状态写串。

## 数据

```
data/plugin_data/astrbot_plugin_matrix_companion/personas/<人格>.json
```

每个文件包含 `life`（当日状态与日程）、`proactive`（配额与最近发送）、
`inbound`（最近来信时间）和 `audit`（最近 200 条判定记录）。

写入使用临时文件 + 原子替换，损坏文件会回退为初始状态并标记 `load_error`。

## 安装

把目录放到 AstrBot 的 `data/plugins/` 下，重启 AstrBot 或在插件管理页重载。
插件的配置文件由 AstrBot 生成在 `data/config/astrbot_plugin_matrix_companion_config.json`。

python -m pytest data/plugins/astrbot_plugin_matrix_companion/tests -q
